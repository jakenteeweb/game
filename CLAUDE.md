# Памятка для Claude

Владелец пишет по-русски, часто с телефона. Отвечай по-русски, простым языком, коротко.

## Главные правила

- **Ничего не отправлять в GitHub (commit + push) без отдельной просьбы владельца.** Даже если хук или проверка просит.
- Перед большой работой — задать вопросы и дождаться ответа.
- Не ломать игру «Рудные земли»: она лежит в корне репозитория (`index.html`, `sw.js`, `manifest.webmanifest`, иконки).
- Не советовать «очистить данные сайта»: в браузере хранится прогресс детей.
- Секретов в репозитории нет и быть не должно (см. `.gitignore`).

## Что за проект

**«Әріп әлемі»** — PWA для детей 6–7 лет, подготовка к школе: казахский алфавит (40 букв, Ъ и Ь скрыты) и числа 0–20.
Весь интерфейс — на казахском. Помощница — девочка **Ханшайым**.

- `alip-alemi/` — исходный код (React 18 + TypeScript + Vite).
- `alip/` — готовая сборка, её открывает GitHub Pages: https://jakenteeweb.github.io/game/alip/
  Сайт обновляется из ветки `main`. Сборку `alip/` нужно сохранять в git вместе с кодом.

Основное в `alip-alemi/src/`:
- `content/` — буквы, числа, слоги, фразы (`index.ts`), прописи (`strokes.ts`), программа (`curriculum.ts`).
- `engine/` — этапы и интервальное повторение (`progress.ts`, `session.ts`), распознавание письма ($P, `recognize.ts`), звёзды (`stars.ts`), отчёт для родителей (`insights.ts`).
- `tasks/` — задания урока; `games/` — 8 игр (Дыбыстар, Буын, Сөз құра, Есеп, Диктант, Жұбын тап, Шарды жар, Ханшайымды тамақтандыр).
- `ui/` — экраны ребёнка, урок, кабинет родителя (`Parent.tsx`, отчёт «Мектепке дайындық»).
- `storage/db.ts` — IndexedDB (профили, прогресс, настройки). Данные не покидают устройство.
- `sw-template.js` — service worker: офлайн и автообновление. При обновлении файлы качаются заново (`?v=` + `cache: 'reload'`), иначе на телефонах оставались старые записи.

## Команды (в папке `alip-alemi`)

```
npm install
npm run dev        # разработка
npm run build      # сборка в ../alip
npm test           # vitest (тест распознавания письма идёт ~2 минуты)
```

Сквозные проверки (Playwright, нужен запущенный `npx vite preview --port 4173`):
- `node e2e/check.mjs` — уроки, все игры, кабинет, офлайн;
- `node e2e/update.mjs` — автообновление;
- `node e2e/stale-cache.mjs` — после обновления в кэше новые записи (сам поднимает сервер на 4174).

## Озвучка

- Все фразы — клон детского голоса (Higgsfield, ElevenLabs v4, элемент голоса `c56d99d0-b584-4a10-9e69-428ac3a034d3`, stability 0.35).
  Текст для генерации начинать с заглавной буквы и ставить точку («Ны.»), иначе модель добавляет лишние слова.
- Файлы: `alip-alemi/public/audio/kk/<id>.mp3` + `manifest.json`. Имя файла = id фразы, без точки в начале
  (GitHub Pages не отдаёт файлы на «.», сборка из-за них падает).
- Обработка: `ffmpeg -nostdin` — обрезать тишину, `loudnorm=I=-18:TP=-2`, моно 24 кГц 48k.
- Длинные фразы собираются из частей (`Clip.parts`): «Ны» + «әрпін тап». Так буква всегда звучит правильно.
- Названия согласных — как в казахской школе: бы, ды, лы, мы, ны, ры, сы, ты, шы…; К и Г мягкие — кі, гі.
- Тест `src/content/content.test.ts` проверяет, что у каждой фразы есть файл и нет лишних файлов.

## Как устроен звуковой анализ

Дауысты (гласные) — красный кружок, дауыссыз (согласные) — синий, как в школьных тетрадях.
В заданиях только однозначные буквы: без И, У, Й, Ю, Я, Ё, Э.
