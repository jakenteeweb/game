# Әріп әлемі

Приложение для детей 4–7 лет: казахский алфавит и цифры. С ребёнком всё общение идёт на казахском, кабинет родителя — на русском.
Это PWA: работает без интернета и без регистрации, данные хранятся только на устройстве (IndexedDB).

- Исходники: `alip-alemi/` (React + TypeScript + Vite).
- Готовая сборка: `../alip/` — её можно открыть через GitHub Pages: `…/game/alip/`.

## Команды

```bash
npm install
npm run dev        # разработка
npm test           # модульные тесты (алгоритм обучения, хранилище)
npm run build      # сборка в ../alip
npx vite preview --port 4173 & NODE_PATH=$(npm root -g) node e2e/check.mjs   # сквозная проверка в браузере
```

## Устройство

| Папка | Что внутри |
|---|---|
| `src/content/` | Контент как данные: 42 буквы, числа 0–20, слова, фразы, контуры для обведения. Порядок и пороги — `curriculum.ts` |
| `src/engine/` | Алгоритм обучения без интерфейса: этапы, освоение, интервальное повторение (`progress.ts`), сборка занятия и адаптация (`session.ts`), наблюдения для родителя (`insights.ts`) |
| `src/storage/` | IndexedDB с версиями схемы и миграциями записей |
| `src/audio/` | Единый аудиоканал (фразы не накладываются), фоновая музыка отдельно от речи |
| `src/tasks/` | Игры: знакомство, узнавание, слушание, обведение, шары, пересчёт, корзина, выбор группы, цифра ↔ количество |
| `src/ui/` | Экраны ребёнка и кабинет родителя |

## Как добавить букву или число

1. В `src/content/letters.ts` добавьте букву в `PREPARED`: слово, картинку, фразу, при необходимости звук.
2. В `src/content/strokes.ts` добавьте контур для обведения.
3. Добавьте id в `CURRICULUM.letterOrder`.

Пока буква не подготовлена (статус `stub`), она не показывается детям.

## Озвучка

Аудио разделено на отдельные фразы: название, звук, слово, инструкция и обратная связь. Порядок источников:

1. Запись носителя языка, загруженная в «Кабинет родителя → Контент и озвучка».
2. Запись в `public/audio/kk/` с регистрацией в `manifest.json`.
3. Синтез с казахским голосом устройства. Он помечается «не проверено» и для изолированных согласных не используется.
4. Без звука.

Русский голос как замена не используется никогда.
