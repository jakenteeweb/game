# Локальный редизайн «Әріп әлемі»

Редизайн реализован в `alip-alemi/`. По просьбе владельца подготовлена обновлённая сборка `alip/` для GitHub Pages. Корневая игра «Рудные земли» не изменена.

## Как открыть

- Сборка из репозитория: http://127.0.0.1:8000/alip/ (до подготовки публикации здесь был оригинал)
- Собранный редизайн: http://127.0.0.1:8001/alip/
- React-исходники с Vite: http://127.0.0.1:5173/

Повторный запуск из корня репозитория, в отдельных терминалах:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

```bash
cd alip-alemi
npm ci --no-audit --no-fund
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

```bash
cd alip-alemi
npm run build -- --outDir /tmp/alippe-redesign/alip
python3 -m http.server 8001 --bind 127.0.0.1 --directory /tmp/alippe-redesign
```

Сборка в `/tmp` позволяет предварительно проверять изменения, не перезаписывая `alip/`. Для публикации нужно выполнить обычный `npm run build` и сохранить обновлённый `alip/` вместе с исходниками.
Разные порты имеют независимые хранилища браузера. При первом открытии нового адреса нужно создать профиль: удержать ⚙️ две секунды, решить пример, добавить ребёнка и выйти из кабинета.

## Что изменено

Светлое главное меню, крупная казахская типографика, Ханшайым и заметная кнопка начала/продолжения обучения. Разделы букв, чисел, игр и сада доступны с главного экрана. Кнопки управления — не меньше 44 px.

Урок букв получил подписи к упражнениям, счётчик и полосу этапов, крупные варианты ответа, текстовую обратную связь после ошибки и верного ответа, подпись «Әрі қарай» и понятное завершение с переходом домой или в сад. Озвучка и повтор инструкции используют прежний аудиоканал.

Не изменены схема IndexedDB, версии и поля профиля/прогресса, учебный контент, планировщик, оценка ответов, распознавание письма и аудиофайлы.

## Проверено в Chromium

Каждый запуск — отдельный изолированный контекст браузера, без пользовательских профилей и данных.

1. До изменений запущены React-исходники. Через кабинет создан ребёнок «Сынақ». Пройден первый урок А: знакомство, узнавание, слушание, возвращение к букве. После reload записи профиля, прогресса и завершённого занятия совпали побайтно при JSON-сравнении.
2. На собранном редизайне повторён тот же путь. Дополнительно сделана ошибка, проверены текстовая подсказка, правильный ответ и адаптивное повторение. Урок завершён, прогресс и звёзды сохранились после reload.
3. Записи из исходной версии загружены в изолированную тестовую базу новой версии и прочитаны без изменений. Следующее занятие пройдено целиком: обведение А сенсорными событиями, знакомство с Н, выбор картинки, узнавание и слушание. Первое задание — повторение А.
4. Проверены повтор озвучки, отсутствие одновременно звучащих фраз, переключение музыки, открытие чисел, сада и списка всех восьми игр. Ошибок JavaScript не обнаружено.
5. Меню проверено на ширине 320, 393, 768 и 1024 px; задания — на телефоне 393 × 851 и планшете 768 × 1024. Проверено отсутствие горизонтального переполнения. Снимки лежат рядом с этим файлом.
6. `npm test`: 36 тестов в 6 файлах прошли. Финальная production-сборка с проверкой TypeScript прошла.

Ограничения: эмуляция Chromium, без проверки на физических устройствах и в Safari. Существующие эмодзи наград/сада зависят от системных шрифтов.


## Дополнительная проверка после первого прохода

Полный существующий сценарий `e2e/check.mjs` завершился сообщением `ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ`:

- Три занятия по буквам и два по числам, обведение сенсорными событиями, шарики, выбор картинок, адаптивное повторение после ошибки.
- Все восемь мини-игр пройдены до конца: Дыбыстар, Буын, Сөз құра, Есеп, Диктант, Жұбын тап, Ханшайымды тамақтандыр, Шарды жар.
- Звёзды за игры: 25 → 64; уровень вырос. В отчёте родителя отмечены все шесть областей; после игр присутствуют результаты по буквам, звукам, чтению, счёту и письму.
- Два ребёнка: у Айко есть прогресс, у Боты он пуст. Проверена загрузка тестовых записей озвучки внутри изолированного браузерного контекста.
- При отключённой сети приложение загрузилось и прошло занятие из десяти заданий.
- В задании «Жаз!» каракули отклонены, А распознана. Озвучка не накладывалась, ошибок JavaScript нет.

После проверки внесены две небольшие правки: новое оформление завершения применяется только к буквам; подсказка о подсвеченном ответе подходит и к буквам, и к картинкам. Исправленный урок чисел отдельно пройден через React-исходники, проверены прежние кнопки домой и в сад. Финальная production-сборка с TypeScript прошла.

Команда полного сценария в текущем окружении:

```bash
cd ~/projects/alippe/alip-alemi
NODE_PATH=/home/ajylb/tools/playwright/node_modules APP_URL=http://127.0.0.1:8001/alip/ node e2e/check.mjs
```

Playwright создаёт отдельный контекст Chromium; пользовательские профили браузера и их данные не затрагиваются.
